# Hoja de Vida

Página web desarrollada en HTML y CSS para presentar mi hoja de vida de manera organizada y profesional.

## Descripción

Este proyecto contiene información personal, perfil profesional, formación académica, experiencia laboral, habilidades, proyectos, cursos y datos de contacto.

La página fue desarrollada utilizando HTML5 y CSS3, incorporando un diseño responsive para que pueda visualizarse correctamente en computadores, tablets y dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- Pico CSS

## Estructura del proyecto

```text
hoja-de-vida/
│
├── index.html
├── styles.css
├── README.md
└── foto.JPG
````

### Archivos

* `index.html`: Contiene la estructura y el contenido de la hoja de vida.
* `styles.css`: Contiene los estilos y el diseño responsive.
* `README.md`: Documentación del proyecto.
* `foto.JPG`: Imagen utilizada como foto de perfil.

## Características

* Diseño responsive.
* Foto de perfil.
* Información personal.
* Perfil profesional.
* Formación académica.
* Experiencia laboral.
* Habilidades.
* Proyectos.
* Cursos y certificaciones.
* Información de contacto.
* Código separado entre HTML y CSS.

## Diseño responsive

La página utiliza `@media queries` en CSS para adaptar el contenido a diferentes tamaños de pantalla:

* Computadores: más de 768 px.
* Tablets: hasta 768 px.
* Celulares: hasta 480 px.

## Cómo ejecutar el proyecto

1. Descargar o clonar el proyecto.
2. Mantener todos los archivos dentro de la misma carpeta.
3. Abrir el archivo `index.html` en un navegador web.
4. La página se mostrará automáticamente.
